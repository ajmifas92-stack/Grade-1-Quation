# 🧠 குழந்தைகள் அறிவு விளையாட்டு — Android

இந்த project கொடுக்கப்பட்ட HTML game-ஐ native Android app-ஆக மாற்றுகிறது.

## Included
- 6 quiz categories
- 20 questions per category
- Tamil text-to-speech (ta-IN)
- Correct / wrong sounds
- Score tracking
- Result screen with stars
- Brain app icon
- Responsive Jetpack Compose UI
- No internet permission required

## Build
1. Android Studio-ல் இந்த folder-ஐ Open செய்யவும்.
2. Gradle Sync முடிந்ததும் Run அழுத்தவும்.
3. APK: `app/build/outputs/apk/debug/app-debug.apk`

## Requirements
- Android Studio Ladybug/Meerkat அல்லது newer
- JDK 17
- Android SDK 35

## App ID
`com.ifas.kidsquiz`

## Note
Android Text-to-Speech engine-ல் Tamil (`ta-IN`) voice installed/enabled இருந்தால் தமிழ் குரல் கிடைக்கும்.
